# 导图工程踩坑全集（2026-08-18 ~ 09-05 六轮返工沉淀）

每条坑都是真实返工的标本。排障时按类别查，动手改图前把「内容组织坑」和「管线坑」通读一遍。

## 一、视觉与文件格式坑

1. **方向真源**：右向靠 rootTopic.extensions 的 unbalanced right-number=N，sheet 级 skeleton（centralTopic: clockwise + mainTopic: logic.right）并用；structureClass 与 sheet 级别的其它字段都不是真源会被压过。C18 试验图 8 个一级分支只带默认值 3，超出的 5 支跑左边被抓——**构建脚本必须自动设 right-number=一级分支数，靠人记必翻车**。
2. **content.json 才是真数据**：content.xml 是「请用新版打开」占位警告页，只改 xml 不改 json=白改（实测翻车一次）。
3. **折叠键**：是 topic 上的 `"branch": "folded"`，不是 `"folded": true`（图像元素属性，不生效）。**教训：动手前先 grep 记忆目录**，agent 当晚未查记忆自造键名，作者打开无折叠实锤返工。
4. **折叠算法**：递归多层预算（子树预算默认 50，超了在最大可见层折叠）+ 被折叠节点内部再超标→嵌套折叠 + **单链不折叠**（展开只加宽度的分叉节点才打标）。
5. **字体**：全局替换 NeverMind→Georgia、STZhongsong→Noto Serif SC；无内联样式的深层节点必须显式挂 fo:font-family=Georgia（深层走主题回退，必须补挂）。
6. **CLI 拼不全**：不要用 CLI 主题参数拼图。以样例 xmind 为模板：解包→只改 content.json（rootTopic.title/children、right-number）→重打包（content.json+metadata+manifest 三个文件，不带 Thumbnails/）。
7. **验证**：`xmind validate` 0 错只是底线；同路径文件被 Xmind 开着时覆盖重开=旧渲染缓存，验证要用副本文件名+taskkill 干净重启；无头渲染验证用 PowerShell PrintWindow+Windows OCR（CopyFromScreen 会被前台窗口遮挡）。
   **内容轮询判据（09-18 能力 14 实测入册）**：抓帧必须按**非白内容占比轮询（5 秒一次），占比 >2% 才算渲染就绪**，**禁固定秒数盲抓**——副本冷启动实测存在约 55 秒全白空白期（0~50 秒占比 0.000，55 秒才 0.078，与历史成功帧 0.093~0.098 同量级），15 秒盲抓＝全白假阴性。配套两条实锤：本机 GPU 合成失效须带 `--disable-gpu-compositing`；Windows OCR 读图须传**反斜杠绝对路径**（WinRT 拒正斜杠）。
8. **关系线已否决**：跨支因果连线（sheet 级 relationships）作者判「看着很乱」，标准=不用。

## 二、内容组织坑（六轮作者批评的病根）

1. **批 merge 叠加=结构烂掉的根因**：同一批内容分多批灌入，同题节点 3 份、问答堆 17 个。→ 一口气到终形态；新内容必须挂计划表走覆盖断言。
2. **同义变体兄弟**：同一命题的不同词序/详略快照并存（指标是自报黑箱/指标是黑箱自报/指标是黑箱）。dedup 只认全同标题，词序变体必须靠 RENAME_MAP 统一或 MERGE_FAMILIES 合并，QA 变体兄弟检负责示众。
3. **机械包装组**：主体/明细1/明细2 是合并脚手架，对冷读者是「无逻辑标签」。正确做法：变体合并把直系子数压到 ≤13，或按内容命名分组（落格候选/排除候选、R1至R9 号段）。
4. **字母码裸奔**：a-f 类型字母码（可蒸出af/蒸不出c/袜子身份证2）当标题，冷读者无从解码。黑话闸只拦纯 ASCII，混合码漏网——QA 字母码检兜底。修法=中文化（可蒸事实偏好）或就地展开命题链（主权卡[单条袜子级/整库升身份证/出门F2]）。
5. **占位符**：显式记住X/禁观察N天 的 X/N 要换成中文（显式记住条目/禁按天数判稳）。
6. **同轴四刀**：同级混流程轴/问答轴/制度轴/实例轴=混轴拉平病；27 支一级收拢成 10 支、17 个问答重切 7 组是修法范本。
7. **问答族完备性**：回答「为什么选 X 不选 Y」必须先列全备选族再逐个否，只出现一个=假穷尽；不属于该族的问题不许混进来。
8. **主张节点=论证链**：标题叫「一句话」的节点=主张+精炼支撑链，禁同义命题平铺。
9. **对比同级必须同构**：和A比/和B比每项同结构（对象/缺什么/强在哪）。
10. **归属优先于形式**：内容挂它服务/解释的对象名下，「为什么叫X」机械分发进 X 词条（NAMING_BELONGS），不许按表面形式归堆。
11. **导览**：每支第一个子节点=「本支讲什么」+1-3 个白话命题孩子；环节一句话必须连读成句（收料定刻度→数据怎么进CM），不懂的导览比没有更糟。
12. **双份定义同步**：同题节点常有多份数据定义（首批登记七条 在 t21/u8），改一处必须 grep 全部同名定义同步改。
13. **前置词典支=解释脱离叙事（09-06 作者三连实锤）**：词表→六类分类法（标签释标签）、背题→背题致失效
    （循环定义）、为什么叫C18 出现在读者没见过 C18 的位置——冷读者按先序读图，「先认词再看正文」的
    词典式支全是无上下文的密码。修法=词汇层整体解散，词条挂正文首用处（首现即释闸），图按叙事读。
14. **命名讨论先于介绍**：「为什么叫X」只能挂在 X 被介绍之后（最好就是首用现场）；「为什么不叫X」豁免
    （X 是被否的备选名无须先介绍）。「为什么有X」按首二字判介绍（版本制←版本）。
15. **复述式定义**：定义位孩子=术语+≤3 字尾巴（背题致失效）对冷读者零信息量。定义必须白话+机制
    （答过的题被背熟/指标从此失真）。
16. **分类层只增不减**：每个新视角/新战役/新问答都倾向新开一支（CM 27 支→10 支→二次臃肿、二号机 13 支）。
    修法=一级预算闸 ≤9 + 归类优先更新纪律 + 二级同刀收敛（问答支解散归机制现场、素材/隐私/内容流收拢）。
17. **词条互踩首用位**：词条 A 的孩子标题提到词条 B 时，B 的首用位就变成了 A 的子树内部——B 的定义必须
    挂进 A 名下或 2 跳内（CM 内核/资产词条挂进 插件/蒸馏 词条名下），挂兄弟组=距离 3 跳=闸拦。

## 三、管线坑（改 cm_data/restructure/rename_map 必读）

1. **链式改名必断**：apply_renames 单次查表不迭代。A→B→C 写法=停在 B。链检查器（mindmap_qa.check_rename_chains，作者本机历史，非本包发布物）已拦截；修法=把中间值键的 value 直接改成终值。
2. **家族 canon 必须=终值标题**：fam[0] 若是 RENAME_MAP 的 key，FAMILY_CANON 会把改名后标题反向解析回不存在的旧标题，take() 静默返回 None，症状是「分支有 N 个节点未被计划覆盖」——先查中毒家族再排查计划表。同题跨支的家族不能建（毒化另一支的引用），只能删。
3. **家族合并要跑不动点**：union_within_branch/dissolve_naming 等重组步骤会把变体兄弟重新拼到同父（wwcd日志×2 实锤），restructure 里 merge_families 在每次重组后再跑。
4. **覆盖断言报错三个根因**，按序排查：①新 L2 节点没挂计划表 ②家族 canon 毒化 ③计划引用了改名中间值。
5. **报告文件时效**：QA/字数报告只在非空时落盘会留旧文件误导——永远覆写或先删。
6. **Mimosa 拦 Bash 直写核心文件**：cm_restructure.py / cm_rename_map.py（作者本机历史，非本包发布物）用 Bash 脚本写会被 PreToolUse 钩子拒，必须走 Edit 工具；cm_data_* 批量补丁 Bash 可过。
7. **检测器自身要被测试钉死**：QA 模块每个检查配正反例 selftest（af 两字母 run、同题跨支假阳性都是 selftest 抓出来的检查器 bug）。

## 四、协作纪律

1. **改标准必须作者点头**，动手前先读本文件和记忆库。
2. **一口气规则**：接到导图任务一口气推到最终形态，禁中途交阶段性版本。
3. **内容素材不确定的不编造**：无素材留白，留白写进覆盖清单（影子层/双轨会话即此类）。
4. **豁免台账带理由**：QA 豁免对（正交两半/互补命题/编号系列/存疑待裁）必须记录理由，禁无理由放行。
5. **验收四条**：冷读者问题清单 2 跳内有答案；路径连读抽查成句；无裸名词；信息量对账（源文件信息 100% 入图或显式留白）。
