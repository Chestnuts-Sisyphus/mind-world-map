## 作者导图叙事校准（09-06 三连：二级分类臃肿 → 词条白话不可懂 → C18 命名先于介绍）

**总定义（09-06 深夜补条，作者原话）**：「实际上思维导图就是针对一个主体的穷尽延伸」——单主体/穷尽/
延伸三推论已写进 skill 总纲（开工第一问=主体一句话钉死；游离内容=跨支重复检；穷尽=信息量对账双向闭包）。

**作者的底层标准（原话钉死）**：「让第一次了解的人只靠读这个思维导图就能理解这个主体的全景和全部细节」。
此前管线检查的全是形式（字数/标点/扇出/术语顺序），没有一个闸管冷读者读不读得懂——图是写给作者自己的
压缩笔记，不是写给第一次读的人的。

**Why**：图按先序阅读=一篇叙事（从上到下、从左到右）。三个实锤样本：①词表→六类分类法（标签释标签，
作者原话「冷读者能看懂吗」）；②背题→背题致失效（循环定义）；③「为什么叫C18→第18号资产」出现在读者
从未见过 C18 的位置——「读者阅读顺序从上至下从左至右，还没出现在叙事中的词就讨论为什么叫XX，冷读者
怎么可能理解，只有在C18旁边解释清楚才是正经合理的叙事节奏」。二级分类臃肿同根：分类层只增不减
（CM 27→10 支后二次臃肿、二号机 13 支），每个新视角都倾向新开一支。

**How to apply**（已焊进管线，见 [[mindmap-engineering-skill]] 与 skill 的冷读者叙事铁律）：
1. **首现即定义**：词的第一次出现处两跳内必须有【定义】X 标记；命名讨论只能挂在介绍之后
   （肯定式为什么叫X/为什么有X 须先介绍，为什么不叫X 豁免）。词典内词（语境术语）查定义存在即可，
   词典外词（真术语）严查首用位置——透明度分层（check_def_locality）。
2. **词条合同**：定义=白话+机制（背题→[答过的题被背熟/指标从此失真]），禁复述术语、禁黑话释黑话。
3. **类目合同**：抽象类目首子=本块讲什么白话；名即内容组进 GUIDE_EXEMPT 带理由（报告级）。
4. **一级预算 ≤9**（check_top_budget 阻断）+ 归类优先更新纪律：新内容先归既有类目，禁新开词典支/平行类目。
5. **词汇层解散**：词典支这种形态本身被否——词条全部搬正文首用处（CM 走 REHOME_HEAD/TAIL/HOLD 迁移台账）。
6. 词条互踩首用位教训：词条A的孩子提到词条B时，B的定义必须挂进A名下或2跳内。

嵌在子树内）。**漏打标不许靠作者**（「靠我的都不是成熟的标准和能力」）→三源归约机器全覆盖。

平行兄弟；被闸拦的图=归类分组后重建，不靠降阈值。**组名命名教训（v3 实测）**：组名不得含"兄弟子树里的话题名"——「取题机制」组因循环五步子树已有「取题」话题被错层闸拦，validate_map 无 keep 台账入口不可豁免，只能改名（「取题机制」→「挑题机制」）；起组名先扫兄弟子树话题名避冲突。

## 分级字数与关系可见（09-12 作者两问：叶子不像人话 / 上下级同级关系不清）

**问题1 叶子不像人话**：2-7 字一刀切——组织节点（导航标签要短）和叶子（内容句要成句）是两种表达任务
却用一个上限，7 字把内容压成电报（断供死锁钟挂）。解=**分级字数闸**：叶子（无孩子）≤12 字成句、组织
节点≤7 字导航（check_title_len leaf-aware，leaf_max 可配）。实测全图零违规=不改现状、给未来成句留空间。
平衡原则：字数限制的目的是短标签/整齐布局/微命题原子——只对组织节点成立；叶子是叙事的内容句，该拿
成句额度；装不下的仍走拆父子命题链。

**问题2 上下级/同级关系不清**：树是分类结构，但刀（为什么同级）和归属（为什么上下级）没说出口；本块讲
什么约定存在但未普适。试过把导览点刀合同扩到全层级→**爆炸**（closure 1661/twin2 96/zhongshen 90）——
深层大量名字自带分类的节点（地界清单/表外动作五问/闭环四步）硬套导览=逼重构，回退。机制边界：结构闸
（数量/错层/同级）抓形式违规；**点刀是语义**=生成纪律（建块就写清这层是什么刀，写不清=没想清）+冷读；
分级字数同时帮关系可读（父=类目短标签、子=成员成句，命题链读法天然说清上下级）。

## mindmap skill 命名 + 无人工自足（09-12 作者定）

**命名**：思维导图生成和更新的能力统称 **mindmap skill**（以后都用这个词）。
**两大铁律（09-12 作者令，已写进 mindmap-engineering/SKILL.md）**：
①**拆链不删词**——一个节点装不下的信息量必须拆成父子命题链（父=类目短标签、子=成员成句），**禁止删词
